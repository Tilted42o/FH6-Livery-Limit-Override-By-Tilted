Layer Limit Override v2.0.0-beta4 - By Tilted42o
=================================================

WHAT THIS BUILD CHANGES

IMPORTANT: STOCK / PROTECTED FH6 BUILDS

If Layer Limit Override detects a known untouched FH6 executable, it shows:

MISSING OFFLINE PATCH

Download and apply the DVS FH6 Offline Patcher first:
https://github.com/DVS-code/FH6-Offline-Patcher/releases/tag/V1

After the offline patch is applied properly, run Layer Limit Override again and
select the patched forzahorizon6.exe.

Shoutout and credit to DVS for the FH6 Offline Patcher.

v1.1 searched for one validated compiler-generated byte layout. That was safe,
but it was still build-sensitive. v2 separates detection from patching:

1. Exact compatibility profiles are checked first.
2. If no exact profile matches, a semantic detector looks for one coherent
   11-entry FH6 layer-limit table and proves the exact immediate operands that
   feed it.
3. The tool refuses to patch if it finds zero candidates, multiple candidates,
   a partial table, mismatched source bytes, or a file that changes mid-process.

The requested limits remain:
- Left / Right / Top: 30,000 layers each
- Other supported surfaces: 10,000 layers each

SAFER BACKUPS

v2 keeps a separate verified backup for each original game build:

forzahorizon6.exe.lu-layers-backup-<12-character-build-hash>

This prevents an old backup from a previous FH6 update from blocking a new
compatible build. v2 can also restore from the old v1.1 backup name when that
backup's hash exactly matches the selected build.

EXTERNAL COMPATIBILITY PROFILES

Keep LayerLimitOverride.profiles.json beside the tool. New exact-build profiles
can be added to that file without rebuilding the EXE. The tool still validates
full-file hashes, every expected original patch byte, the staged output and the
final installed file.

IF A BUILD IS STILL UNSUPPORTED

The tool does not modify it. It can create a small compatibility report beside
the tool (or in the Windows temp folder if needed). The report contains SHA-256,
PE metadata, detector counts and at most a few tiny code windows around possible
layer-table anchors. It does NOT contain the full game executable or a memory
dump.

Send that JSON report together with the person's FH6 version and storefront.

USE

1. Extract the whole ZIP to a normal folder.
2. Close Forza Horizon 6.
3. Run "Layer Limit Override v2 - By Tilted42o.exe".
4. Select the installed forzahorizon6.exe.
5. If the MISSING OFFLINE PATCH screen appears, use the DVS download link shown.
6. Apply the DVS offline patch properly, then run Layer Limit Override again and
   select the patched forzahorizon6.exe.
7. When a compatible prepared build is detected, read the detector/build shown
   in the confirmation box and apply the override.
8. Run the same tool and select the same executable again to restore its
   verified original backup.

Do not delete a build-specific backup if you want one-click restore for that
build.

BETA STATUS / VERIFICATION

This is a compatibility-engine beta, not a claim that every future FH6 compiler
layout is automatically patchable. Unknown layouts still fail closed and can be
added through profiles.

Verified in the supplied source/test environment:
- exact reference executable recognition
- semantic fallback on that executable after unrelated file variation
- 22 changed bytes only on the reference semantic fallback
- reordered layer-table initialization
- alternate direct 16-bit initialization form
- original and already-overridden table recognition
- rejection of ambiguous and partial candidates
- hash-specific backup creation and restoration
- restoration from the legacy v1.1 backup filename
- Windows x64 GUI cross-build

The Windows GUI itself cannot be launched in this Linux build environment. Test
this beta on a COPY/verified installation first, especially on builds that v1.1
currently rejects.
